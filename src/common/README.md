# common/

Mã dùng chung xuyên suốt các module:

```
common/
  filters/        # exception filters (PART 2.2)
  interceptors/   # response transform, logging (PART 2.2)
  decorators/     # @CurrentUser, @Roles, ... (PHASE 3)
  guards/         # JwtAuthGuard, RolesGuard (PHASE 3)
  dto/            # PaginationDto, ... (PART 2.2)
```

Chưa tạo nội dung ở PART 2.1 — sẽ bổ sung đúng PART yêu cầu.
